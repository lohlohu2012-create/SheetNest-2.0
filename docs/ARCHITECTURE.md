# SheetNest 2.0
Native desktop application: Qt 6/C++20 UI over an independent nesting core.

Optimization objective:
1. Minimize number of metal sheets.
2. For equal sheet count, minimize material waste.

Roadmap: robust DXF geometry -> true-shape collision/NFP -> multi-start optimization -> parallel search -> global compaction -> interactive CAD editing -> DXF export.

The existing browser SheetNest is reference material only; it is not the runtime architecture.
