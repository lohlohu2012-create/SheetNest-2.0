# Laser cutting time
SheetNest 2.0 includes a 3 kW Bodor reference technology table.

The estimate is based on:
- actual total contour length;
- material;
- sheet thickness;
- reference cutting speed;
- number of piercings;
- rapid/traverse distance.

Objective: estimate machine time for a nesting result, not certify production parameters.

Bodor's published documentation states that cutting parameters are reference values and depend on plate quality, gas, optics, focus, nozzle and other site conditions. Production values must therefore be calibrated against the user's machine and material batch.

The initial database uses conservative midpoint/reference speeds derived from published 3 kW Bodor tables. It should be replaced or supplemented with the exact parameter table for the user's specific Bodor machine and laser source.
